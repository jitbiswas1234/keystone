# 🎟️ KeyStone - Event Booking & Management Platform

## 📌 Overview

KeyStone is a full-stack Event Booking and Management Platform designed to simplify event discovery, registration, ticket booking, and event administration. The platform enables users to browse events, book tickets online, make secure payments, manage bookings, and download invoices, while administrators can efficiently manage events and monitor bookings through a centralized dashboard.

The application includes a condition-based chatbot for user assistance, secure payment gateway integration, and PDF invoice generation, providing a seamless experience for both organizers and attendees.
