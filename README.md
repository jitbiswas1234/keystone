KeyStone is a comprehensive Event Booking and Management Platform built with PHP and MySQL. The application enables users to browse events, book tickets, complete secure online payments via Razorpay, download booking invoices, and manage reservations through a personalized dashboard. The platform also includes an admin panel for event management and a condition-based chatbot for automated customer support. Developed using Laragon and deployed through cPanel, KeyStone demonstrates full-stack web development, payment integration, and database management capabilities.
